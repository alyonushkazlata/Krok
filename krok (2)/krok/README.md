# Крок — навчальна платформа (алгебра та геометрія 6–10 класів)

Дерево тем з передумовами → пояснення «простими словами» → розібрані приклади → задачі, що генеруються з нуля, з підказками і розбиттям на кроки → тест → інтервальне повторення → діагностика прогалин.

## Запуск

```
npm install
npm run dev        # http://localhost:5173
npm run build      # статичний сайт у apps/web/dist (можна хостити будь-де)
npm test           # тести ядра (перевірка відповідей, прогрес)
npm run validate   # перевірка всіх тем: генератори, відповіді, LaTeX
```

Потрібен Node 20+. Прогрес зберігається в браузері (localStorage), є експорт/імпорт файлом на сторінці «Прогрес».

## Структура

- `packages/core` — рушій без прив’язки до предмета: типи, генератор випадкових чисел, перевірка відповідей (числа, дроби, корені, вирази, проміжки, вибір), трекінг освоєння, інтервальне повторення, підбір задач, `mdToPlain` для Telegram.
- `packages/content` — предмети й теми. `algebra/curriculum.ts` і `geometry/curriculum.ts` — карта програми (усі теми з передумовами; ненаписані показуються як «скоро»). Тема = файл `g<клас>/<id>.topic.ts`.
- `apps/web` — React-застосунок (українська, світла/темна тема, мобільний вигляд).
- `CONTENT_GUIDE.md` — як писати теми (планка якості, типи відповідей, малюнки).

## Додати тему

1. Знайди її в `curriculum.ts` (id і розділ).
2. Створи `packages/content/src/<предмет>/g<клас>/<id>.topic.ts` за зразком `algebra/g8/a8-quad-formula.topic.ts` (алгебра) або `geometry/g7/g7-angles.topic.ts` (геометрія з малюнками).
3. `npm run validate -- <id>` — має пройти без помилок. Тема з’явиться на сайті автоматично.

## Додати новий предмет (фізика, хімія, мова…)

Створи `packages/content/src/<предмет>/curriculum.ts` (розділи й карта тем) і папки `g<клас>/`; додай предмет у масив `subjects` у `packages/content/src/index.ts`. Ядро не залежить від математики: підтримуються відповіді числом, виразом, вибором, текстом.

## Telegram-бот (наступний етап)

Ядро навмисно не залежить від React: бот підключає `@krok/core` + `@krok/content`, бере `nextProblem`, перевіряє `checkAnswer`, показує текст через `mdToPlain` (формули → Unicode), зберігає `ProgressState` у файлі/SQLite через інтерфейс `ProgressStore`. Для синхронізації з сайтом — експорт/імпорт прогресу вже є.

## Стан контенту

Дивись `npm run validate` (в кінці: «готових тем: N/M»). Карта програми: 6–10 класи, ≈130 тем.
